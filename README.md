# Yijia Xie · Field / Flux / Scale

Interactive research presentation covering field observations, ecosystem–atmosphere measurements, GIScience, and Earth-system modelling.

## Controls

- Arrow keys, mouse wheel, or swipe to navigate
- `O` for slide overview
- `N` for speaker notes
- `F` for full screen

The two course-photo slots support local browser previews. Selected images remain on the viewer's device and are not uploaded.
